First release of LarkBar, a menu bar app for Hollyland Lark wireless mics.

### What it does
- Detects the plugged-in Hollyland receiver and updates when you plug it in or out.
- Shows each mic's battery, with the lowest one in the menu bar.
- Mute mics and change gain, noise cancelling, EQ, reverb, mono/stereo, auto power off, signal
  mode, status light, performance mode and identify. Restart the receiver.
- Open at Login.

### Supported receivers
- **Lark A1** USB-C receiver: supported.
- **Lark M2** USB-C receiver: experimental (batteries, gain, noise cancelling, restart). Reports welcome.

### Install
Download `LarkBar-0.0.1.dmg`, open it, and drag LarkBar to Applications. Requires macOS 14 or later.

Signed with a Developer ID and notarized by Apple, so it opens without warnings.
