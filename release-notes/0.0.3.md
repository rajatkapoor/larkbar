### New
- **Automatic updates.** LarkBar now checks for new versions once a day and asks before installing
  one. You can also choose **Check for Updates…** in the menu. When a new version is found, the menu
  shows "Update Available". Updates are signed, and LarkBar only installs ones signed by us.

### Install
Download `LarkBar-0.0.3.dmg`, open it, and drag LarkBar to Applications (replace the old copy if
asked). Requires macOS 14 or later. Signed and notarized by Apple. This is the last version you need
to install by hand: from here on LarkBar updates itself.
